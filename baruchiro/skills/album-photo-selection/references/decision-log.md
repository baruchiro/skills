# Decision log

Keep a small log outside the repo and outside any photo archive, in a place the user chooses. Identify photos by whatever stable ID or file name the user's tool provides, and never copy images into it.

Record, per decision:
- Intent sentence for the album.
- Group (moment, event, chapter) and the IDs in it.
- For each photo: status (in, alternate, out of this album, undecided) and the role or reason, for example "B: representative portrait; C: alternate; D: key action; E: relationship and ending; F: only if a detailed holiday chapter is chosen".
- Who decided: the user, or a suggestion from a tool that the user accepted.
- Open questions and the stage the group has reached.

A role and reason explains later choices better than a single quality score. "Out of this album" does not mean deleted.
