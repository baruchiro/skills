# Steimatzky search and product verification

This is a read-only browser procedure for https://www.steimatzky.co.il/, not an executable adapter or a stock API. No account is needed for public search. Do not add to cart, purchase, reserve or sign in as part of a book lookup.

## Search

1. Open the homepage and use the search textbox labeled `חיפוש`. Enter the full requested title and submit with Enter or the `חיפוש` button. Search the author separately in the same field. Preserve spelling variants as separate queries until identity is verified. A cookie consent banner can cover the page on a first visit; dismiss it before interacting.
2. The observed search route is `/catalogsearch/result/?q=<URL-encoded query>`. Prefer the current site's visible search UI; use a saved route only after confirming that it still performs the intended search. Do not invent legacy search endpoints. The observed robots.txt excludes this search route from automated access; keep checks small and manual-style, and see [site limits](site-limits.md).
3. Check the rendered results heading `תוצאות חיפוש עבור: '<query>'` and let the product list finish rendering before reading it; an early read of a still-loading page can look empty and is not zero results. Record each search URL and whether it returned results, the explicit empty marker `לא נמצאו תוצאות לחיפוש שלך`, an error or an incomplete page. A blank/loading page or failed request is not zero results. No result count was observed. If site search fails, a site-scoped web search can supply candidates, not exhaustive coverage.
4. Follow result links to the main product page. Product URLs observed are numeric IDs (for example `/011320475`). Keep the resolved URL, omitting only verified tracking parameters, and deduplicate by that URL. Results mix books with non-book merchandise such as puzzles and headphones; match identity before following a link. Pagination was not observed on the checked result pages; if more results cannot be inspected, report incomplete coverage rather than guessing an endpoint or a total.

## Verify the main product

5. Match the main title and author, requested language, translation, edition and volume. Author names link to `/סופרים/<author>` pages. No publisher, publication year, binding, translation or ISBN details were observed on the checked product page; keep missing edition details unknown. A search hit or cover alone does not settle identity.
6. Record the format separately: cards and products distinguish `מודפס` (print) from `דיגיטלי` (digital, sometimes labeled DIGITAL PRO), and one card can show a print price and a digital price side by side. Record each format's `מחיר מוצר` (selling price) separately from `המחיר הקטלוגי של הפריט` (the catalog/list price). A promotional category page such as `/sale/...` advertises a shelf price; verify the rendered price on each main product page. A product price is not a checkout total including delivery or fees. If no selling price settles, report price unknown. The site banner states online prices are not valid in branches.
7. Report availability separately from price. A `הוספה לסל` control establishes a purchase option was displayed, not confirmed physical stock. No explicit availability text was observed on the checked product page; if none is present, say availability unknown and optionally note the displayed purchase option. Do not borrow stock or prices from recommendations, bestseller strips or unrelated cards. No branch-level stock, reservation or successful checkout is verified by this procedure; the site itself notes branch prices differ.
8. Return the verified title/author/edition and format, resolved product URL, observation timestamp, displayed selling price/currency and availability evidence or unknowns. Avoid plot details and spoilers. Keep personal queries, wishlists and captured website content outside this package.

## Validation and limits

A small public-browser check on 2026-11-19 exercised one full-title query, one author name in the same search field, an explicit empty-result query, the matching main product's identity, format and rendered selling price versus catalog price, and a promotional sale category page. These examples do not establish exhaustive indexing, spelling tolerance, pagination behavior, all editions, physical stock or checkout success. No Steimatzky scraper or automated browser test is shipped. The offline documentation tests check this guide's required distinctions, not live site behavior.

Read [site limits](site-limits.md) and the site's current access rules before use. Stop on rate limiting or access denial; follow the host's browser/security rules for challenges. Keep checks small and sequential. Do not use this procedure for bulk crawling or unattended monitoring. If the page changes or required details cannot be verified, preserve completed evidence and report the specific coverage gap.
